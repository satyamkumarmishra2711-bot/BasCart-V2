BasCart Deployment Setup

If you see this screen on GitHub Pages, your repository is serving uncompiled source code instead of the production build.

How to activate your GitHub Pages deployment:
1. In your GitHub repository, open Settings → Pages.
2. Under Build and deployment → Source, change the dropdown from Deploy from a branch to GitHub Actions.
3. Go to the Actions tab, click Deploy to GitHub Pages, and click Run workflow.
4. Once the green checkmark appears, refresh this page!
